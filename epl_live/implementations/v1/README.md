# Initial executed implementation

These twelve files are byte-identical copies of the sources and protocols used
for the initial October 14 release. Their original paths and SHA-256 hashes are
in [manifest.json](manifest.json). Recompute the forecast code hash from the ten
Python-file hashes, using the original Windows relative path spelling and the
same sorted JSON encoding used by the archived `run.py`.

This is a provenance archive. Run the active modules in `epl_live` from the
project root; the archive is not a separately configured Python package.
