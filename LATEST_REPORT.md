# Latest EPL project report

**Updated October 15, 2026.** Open the stable folder **`reports/latest/`**:

- [Latest report - PDF](reports/latest/EPL_Project_Report.pdf)
- [Latest report - editable Word](reports/latest/EPL_Project_Report.docx)

The report adds four-season stability for the 56 strategies with available
rolling forecasts, while retaining the original all-84 strategy comparison.
Both money-versus-time graphs start each strategy at 100,000. Every account has
hit ratio, expected gain/loss, realized payoffs, trading frequency and risk
metrics. The final appendix explains all 84 strategy configurations and their
historical coverage.
